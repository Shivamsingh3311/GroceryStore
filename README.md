
# 🥬 FreshMart — Online Grocery Store

FreshMart is a modern, responsive online grocery store website built using HTML, CSS, and vanilla JavaScript. It lets users explore everyday grocery essentials, search for products, filter categories, manage a shopping cart, and try a demo checkout.

## ✨ Features

- **Modern UI:** Clean, attractive grocery shopping interface.
- **Responsive design:** Works on desktop, tablet, and mobile devices.
- **Product catalog:** Fruits, vegetables, dairy, bakery, and snacks.
- **Search functionality:** Find products by name, category, or description.
- **Category filters:** Browse groceries by category.
- **Shopping cart:** Add products, remove products, and change quantities.
- **Automatic calculations:** Dynamic subtotal, delivery charge, and final total.
- **Free delivery:** Orders worth ₹499 or more qualify for free delivery.
- **Checkout interface:** Enter customer details and try a demo order.
- **Newsletter form:** Interactive front-end subscription demonstration.
- **No framework required:** Built using plain HTML, CSS, and JavaScript.

## 🚀 Getting Started

### Prerequisites

- A modern web browser.
- A code editor such as Visual Studio Code.

### Installation

1. Clone the repository or download the project files.
2. Open the project folder in your code editor.
3. Make sure all four files are in the same directory.
4. Open `index.html` in your browser.

You can also use the **Live Server** extension in Visual Studio Code to preview the website while editing.

No package installation or build process is required.

## 🛒 How to Use

1. Browse the available grocery products.
2. Select a category to narrow down the products.
3. Search for a grocery item using the search bar.
4. Click **+ Add** to add a product to your cart.
5. Open your cart to change quantities or remove items.
6. Review the subtotal, delivery fee, and total.
7. Click **Proceed to checkout** and enter demo delivery details.
8. Place a demo order to test the checkout flow.

## 💰 Delivery Rules

- Orders below ₹499 have a demo delivery fee of ₹40.
- Orders of ₹499 or more qualify for free demo delivery.
- Prices and delivery rules can be changed in `script.js`.

## ⚠️ Important Limitations

This project is a front-end demonstration, not a production-ready e-commerce platform.

- Products are stored in a JavaScript array.
- Cart contents are kept in memory and reset on page refresh.
- Checkout does not create a real order.
- No payment gateway or backend is connected.
- The newsletter form does not store email addresses.
- Product images and Google Fonts require an internet connection.
- Product prices and stock availability are illustrative and should be verified before real-world use.

Do not enter real customer information into the demonstration checkout.
